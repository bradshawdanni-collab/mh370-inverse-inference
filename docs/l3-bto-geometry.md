# L3 BTO Geometry and Range Rings

## Purpose

L3 converts an explicitly calibrated Burst Timing Offset into a one-way satellite-aircraft slant range and then solves the corresponding constant-altitude WGS84 candidate arc.

The layer is deterministic and geometry-only. It does not rank candidates, fit trajectories, fuse BFO constraints, or embed historical calibration constants.

## Existing foundation

L3 extends the repository's existing components:

- `satcom.bto` for timing conversion;
- `satcom.wgs84` for geodetic/ECEF transforms;
- `satcom.geometry` for Euclidean slant range and WGS84 geodesics;
- `satcom.arc` for closed arc generation.

## Calibrated BTO conversion

Given total round-trip timing `t_bto` and an explicit calibration delay `t_cal`:

```text
t_corrected = t_bto - t_cal
slant_range = c * t_corrected / 2
```

The corrected timing must be non-negative. Calibration is a caller-supplied input and is never hard-coded.

The existing signed timing-error conversion remains separate because a range error and an absolute slant range are different quantities.

## WGS84 candidate geometry

For a satellite ECEF position `r_sat` and a candidate geodetic point converted to ECEF as `r_candidate`:

```text
slant_range(candidate) = |r_candidate - r_sat|
residual(candidate) = slant_range(candidate) - target_slant_range
```

For each requested azimuth from the satellite subpoint, L3 searches outward along a WGS84 geodesic at the supplied candidate altitude. It brackets the first residual sign change and then applies deterministic bisection until the absolute residual is within the configured tolerance.

The solver returns the first outward root. This makes the root-selection rule explicit and replayable.

## Arc generation

A candidate arc is generated by solving the same target slant range at uniformly spaced azimuths:

```text
azimuth_i = i * 360 / point_count
```

The first point is appended to the end so the returned arc is closed. A residual is retained for every point, including the closing point.

## Failure discipline

L3 fails closed when:

- BTO or calibration inputs are non-finite;
- corrected BTO timing is negative;
- target slant range is negative or non-finite;
- candidate altitude is negative or non-finite;
- tolerance, search bound, or iteration count is invalid;
- target range is below the nadir range;
- no outward root is bracketed within the configured search distance;
- the solver does not converge within its deterministic iteration limit;
- fewer than four arc points are requested.

## Scope boundaries

The generated arc is a geometric constraint, not a probability distribution. L3 does not infer which point is most likely and does not combine the arc with BFO, aircraft reachability, weather, fuel, or Bayesian weights.

Those integrations belong to later milestones.
