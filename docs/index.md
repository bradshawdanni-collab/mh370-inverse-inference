# MH370 Inverse Inference

This documentation defines a modular, reproducible framework for evaluating MH370 impact-region hypotheses.

## Current phase

The project is at **L0: SATCOM geometry**. The first objective is to reproduce published BTO-derived arcs and uncertainty bands before adding aircraft dynamics, debris transport, search non-detection, or biological evidence.

## Non-claim

This repository does not assert an exact crash location. It ranks and rejects regional hypotheses under explicit assumptions and uncertainty models.
